Mozilla PDF.js 6.5.438 legacy distribution (Apache-2.0).
Source: https://github.com/mozilla/pdf.js/releases/tag/v6.5.438
Archive: https://github.com/mozilla/pdf.js/releases/download/v6.5.438/pdfjs-6.5.438-legacy-dist.zip

SenseDex integration: added web/sensedex.css and site title; disabled PDF scripting, annotation editing, ML model downloads, and persisted preferences; removed the sample PDF and source maps; retained English localization. Other runtime assets and license notices are preserved.

ActiveSPN profiles: web/activespn.js and web/activespn.css apply only to profile=activespn with activespn.pdf and profile=activespn2 with activespn2-author.pdf. They enable native local annotations, automatic zoom and a responsive outline. The supplied PDFs have no bookmarks, so each profile supplies its own outline without changing either PDF. ActiveSPN uses measured heading positions. ActiveSPN2 uses the author's searchable 14-page vector version (http://www.senli.site/files/2025-J-BIROB-LiDeformable.pdf), with native named section/subsection destinations and a measured abstract heading; this version has no separate CRediT, declaration, acknowledgments or appendix sections. The original 13-page image-only activespn2.pdf remains a separate article-in-press download and is not assigned the vector version's outline. A future PDF's embedded outline takes precedence. Scripting and ML downloads remain disabled. Other papers retain the default reader configuration.
