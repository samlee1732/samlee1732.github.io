Course Description

This course connects fundamental robotics concepts with practical implementation. Students will study robot structures, coordinate transformations, kinematics, robot modeling, programming, and motion planning. Examples from robotic manipulation and industrial applications provide context for understanding how these elements work together.

Practical work will use the DR-xcobo 2.0 as the course platform, with an emphasis on URDF modeling, Python interfaces, and MoveIt-based motion planning. Students will develop and validate applications in simulation, document their results, and communicate their design decisions. Hardware activities will be arranged according to platform availability and the teaching schedule.

Learning Outcomes

By the end of this course, students should be able to:

  1. Describe robot structures, coordinate frames, workspaces, and basic motion constraints.
  2. Apply coordinate transformations and basic kinematics to represent and analyze robot motion.
  3. Build and validate a URDF model with appropriate links, joints, and joint limits.
  4. Use Python interfaces and MoveIt to program and test basic robot motions.
  5. Integrate a simple robotic application and present its implementation, test results, and limitations.

Assignments & Projects

Proposed coursework. Task briefs, submission instructions, and team size will be added when available.

Assignment 1: Kinematics in Python

Implement coordinate transformations and forward kinematics for an instructor-provided model. Submit code, validation examples, and a short explanation.

Assignment 2: Robot Model & Interface

Complete a URDF model and use a Python interface to issue basic joint commands and read robot states in simulation. Submit the model, code, and a short demonstration.

Team Project: Midterm Presentation

Present the proposed application, division of work, robot model, and initial validation results. Explain the coordinate frames, joint limits, and remaining implementation tasks.

Course Project: Final Showcase

Demonstrate a robotic application combining the robot model, Python code, and MoveIt planning. Submit an executable demonstration, test results, and a concise technical report.
